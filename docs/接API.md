# 駁 API：由「起到個殼」到「真係寫到稿」

到你撳完精靈、開好客之後，工作台有齊架構但寫唔到嘢 —— 因為冇接任何 AI 服務。
呢一頁講點接，同埋接完之後實際會發生咩。

---

## 一、攞一條 API key

去 **console.anthropic.com** 開戶口 → API keys → Create key。
複製條 key（`sk-ant-…` 開頭）。

**呢條 key 只顯示一次。** 抄低咗先閂窗。

---

## 二、告訴你部機

Mac 開終端機，貼呢兩行（把 `sk-ant-你條key` 換成真嘅）：

```bash
echo 'export ANTHROPIC_API_KEY=sk-ant-你條key' >> ~/.zshrc
source ~/.zshrc
```

> 呢條 key 等於你個荷包。唔好貼落任何對話、Slack、截圖、或者 git。
> 上面嗰句係寫入你自己部機嘅設定檔，唔會傳去任何地方。

驗一驗：

```bash
python3 -c "import os; print('OK' if os.environ.get('ANTHROPIC_API_KEY') else '未設定')"
```

裝返 SDK（一次過）：

```bash
pip install anthropic
```

## 三、跑一條真內容

生產線分兩段，中間有一道人手閘 —— 唔係一撳就出稿。

### 第 1 步：出候選角度

```bash
python3 -m workbench angles mamis-sunshine "產後恢復嘅三個誤解"
```

出 3–6 個角度，寫入 `queue/01-insights/`，**然後停低**。

停係故意嘅。角度錯咗，下游成條線做嘅都係錯題目。呢個係第一道人手閘。

### 第 2 步：你揀一個，佢寫稿

```bash
python3 -m workbench draft mamis-sunshine "產後恢復嘅三個誤解" "角度A：破除時間迷思"
```

會做三件事：

1. **寫稿** —— Master ＋ 每個平台版本（每個平台重新寫開場同節奏，唔係複製貼上）
2. **機械式檢查** —— 由紅線抽出禁用詞，逐個字串搵。唔靠模型自覺
3. **模型 QA** —— 判斷機械檢查做唔到嘅嘢（暗示性宣稱、語氣偏差、扮引用）

**兩層都要過。** 過咗入 `queue/03-approved/` 等你批。
過唔到留喺 `queue/02-drafts/`，入面寫明違反邊條、應該補去邊一層。

出街之前仲有一道人手閘：你自己撳批准。**冇嘢會自動發布。**

---

## 四、兩層 QA 係咩意思

模型 QA 都係一個模型。叫模型審自己有冇違反紅線，係自我審查 ——
而自我審查唔滿足合規要求。所以有第一層：

| | 做咩 | 靠咩 |
|---|---|---|
| **機械層** | 搵禁用詞、搵無出處數字 | 字串比對。搵到就係搵到，冇得拗 |
| **模型層** | 暗示、語氣、扮引用 | 判斷 |

機械層攔咗，模型話 pass 都唔算數。呢個唔係唔信模型 ——
係「兩個獨立檢查都要過」本身就係設計。

機械層抽唔到詞嗰幾條紅線（例如「個案分享要有書面同意」），
會**明明白白列出嚟**話你知「呢條要人睇」。唔列就會變成「檢查過」嘅假象。

## 五、成本：呢度先係大頭

每寫一篇稿，模型都要讀品牌憲法、語氣檔、已批准證據、平台規格 ——
加埋成 3,000 字元，而且**每次一模一樣**。

所以品牌知識庫做咗 **cached prefix**，TTL 1 小時（研究→文案→QA 通常喺一兩個鐘內跑完；
預設 5 分鐘會喺中間過期）。

每次跑完會印實際用量：

```
  用量  2 次呼叫 · 檔次 standard
        文案（Master）   claude-opus-5   in 100 out 50  快取命中 8000
        QA／紅線檢查      claude-opus-5   in 100 out 50  快取命中 8000
```

**「快取命中」係 0 嘅話，重複跑幾次都係 0，就係前綴唔穩定** —— 見 `workbench/brain.py` 開頭。
冇快取，你嘅帳單大部分係喺度重複讀同一份檔案。

### 預設全部用 `claude-opus-5`

我之前份成本文件建議過分層用平模型。**但降級係你嘅決定，唔係我幫你做。**
所以預設全部行 opus-5。想試分層：

```bash
export WORKBENCH_TIER=economy
```

開咗之後：抽取同分流落 Haiku，平台改寫落 Sonnet，
**研究、文案、QA 唔郁**。QA 標咗永遠唔降 —— 佢係最後一道攔截，
攔唔到就出街，出街咗嘅嘢收唔返。一次違規貴過成年嘅模型差價。

第一方 API 價（每 1M token，2026-06 快照，落單前核返）：
`claude-opus-5` $5／$25 · `claude-sonnet-5` $2／$10 · `claude-haiku-4-5` $1／$5

## 六、你兩個客而家會點

你 dashboard 上面兩個客嘅 `04-approved-claims.md` **都係空**。

所以就算你而家跑 `draft`，出嚟嘅稿**一個數字都唔會有**，
而且任何數字都會被機械層攔住。呢個唔係壞咗 —— 呢個係設計。

想解鎖，交呢啲入 `brand/brain/04-approved-claims.md`：

| 你交咩 | 解鎖到咩 |
|---|---|
| 證書掃描件（TQUK、資格） | 可以寫「導師持 X 資格」 |
| 有書面同意嘅個案 | 可以寫個案、前後對比 |
| 內部預約／銷售記錄 | 可以寫「已服務 N 位」 |

每一行要寫低：**主張、證據、授權範圍、到期**。

同時交 20–30 條真實查詢紀錄（WhatsApp／DM，抹走個人資料）入
`03-audience-language.md` —— 冇呢個，內容會用你嘅講法寫，
而唔係客人搵嘢時打嘅字。

## 七、仲未接嘅嘢

老實講清楚：

- **生圖未接。** 架構同規格寫好晒（`style/brand-visual.md` 有顏色同「從來冇出現」欄），
  但未叫任何圖像 API。要接嘅話同我講你有邊個服務嘅帳號。
- **爬取未接。** 「學你嘅語氣」要有語料。而家要人手匯出貼文再跑 `distill.py`。
  工作台唔會自動登入去攞你嘅帖。
- **Batch API 未接。** 呢個工作台天生啱用（所有嘢都入佇列等人審，冇一篇即時出街），
  接咗大約平一半。未做。
- **排程發布未接。** 而家只排到待審。

頭兩樣係「內容質素」嘅前置條件，後兩樣係「慳錢同慳時間」。
建議次序：先補證據庫 → 跑三個真 campaign → 睇實際塞喺邊 → 先決定接下一樣。
