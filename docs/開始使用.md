# 點樣用呢個工作台

> 呢一頁唔需要任何電腦知識。跟住做就得。

---

## 一、開機（一世人做一次）

打開你部電腦嘅**終端機**：

- Mac：撳 `Command + 空白鍵`，打 `terminal`，撳 Enter
- Windows：撳開始鍵，打 `powershell`，撳 Enter

貼呢一行落去，撳 Enter：

```
python3 -m workbench start
```

瀏覽器會自己彈開。見到「工作台狀態」四個字就成功。

**如果話搵唔到 python3**：即係部機未裝過。去 python.org 下載，安裝嗰陣記住剔
「Add Python to PATH」。裝完再貼一次上面嗰行。

之後每次想開，都係貼返同一行。

---

## 二、開一個新客（大概三分鐘）

撳右上角綠色嘅 **＋ 開新客**。

跟住有六步。**每一步都已經幫你揀好咗嘢** —— 你只需要睇一眼，唔啱先撳走。

### 第 1 步 · 你做邊行？
撳一個最似你嘅。十三個行業，每個下面有一句解釋。

撳完之後，第 3、4 步嘅選項會**自動跟住變** —— 因為一間茶餐廳同一間客服中心，
需要嘅嘢根本唔同。

### 第 2 步 · 係咪講中咗你？
呢度會話返俾你聽：**你而家塞喺邊**、**工作台拆開咗咩**。

下面有幾個「合規」按鈕，通常已經幫你㩒好咗。呢啲係「講錯要負責任」嘅範疇 ——
講健康、講功效、講錢、涉及小朋友。㩒一個，下面條紅線清單就會即刻變長。

**唔關你事嘅就撳走。** 但唔好為咗少幾條規矩而撳走一個真係適用嘅 —— 
嗰啲規矩係保護你，唔係阻你。

### 第 3 步 · 你喺邊度出內容？
已經按你個行業揀咗常用嗰幾個。加減都得。

### 第 4 步 · 想佢幫你做啲咩？
一格格寫住「學你嘅語氣」「做圖」「分流留言私訊」—— 講你會得到咩，唔係講技術名。

有三格係㩒唔郁嘅（灰色）：嗰啲係基本盤，冇咗就唔算一個工作台。

你揀嘅嘢會決定請幾多個崗位。撳「做圖」，下面就會自動多咗個「視覺」崗位 ——
你唔使識咩叫 agent。

### 第 5 步 · 你嘅圖係咩樣？
**掉幾張你出過嘅圖入去個框。** 建議十張以上。

放手嗰刻，工作台會即刻讀返你嘅顏色，出一排色塊俾你睇。

> **啲相唔會離開你部機。** 分析係喺你個瀏覽器度做，只有算出嚟嘅色碼會存低。
> 如果你啲參考圖係客人身體（例如產後個案），呢點好緊要。

唔想做可以直接撳下一步。之後補得返。

### 第 6 步 · 睇一眼就開工
最後一版會列晒：品牌、平台、崗位、**同埋每一條紅線**。

睇完撳 **建立工作台 ✓**。

---

## 三、開完之後，仲差兩樣

工作台會直接話你聽。呢兩樣**機器補唔到**，一定要人交：

**1. 已批准嘅證據** —— 證書、有同意書嘅個案、有出處嘅數字。

冇呢個，所有稿都唔可以出任何數字或個案。唔係「唔建議」，係**真係會被攔住**。
呢個係故意嘅：一句冇出處嘅宣稱出咗街，收唔返。

**2. 真實客戶查詢紀錄** —— WhatsApp、DM、留言，二三十條，抹走個人資料。

冇呢個，內容會用**你嘅講法**寫，而唔係**客人搵嘢時打嘅字**。

---

## 四、日常點睇

返去主頁（撳左上角「工作台狀態」）。每個客一張卡，左邊個圓點就係佢而家嘅狀態：

| 圓點 | 意思 | 你要做咩 |
|---|---|---|
| 🔵 藍 · 待設置 | 啱啱開，未有料 | 交料。未開工缺料好正常，唔使慌 |
| 🔴 紅 · 阻塞 | **有稿，但出唔到街** | 睇卡入面寫住差咩，補返 |
| 🟡 黃 · 等人審 | 行緊，等你㩒批准 | 去審。呢個係正常運作嘅樣 |
| 🟢 綠 · 運作中 | 全條線通咗 | 冇嘢做。好事 |

每張卡最底有一行「**下一步**」。成個工作台入面你只需要睇嗰一行。

## 五、成日有人問

**要唔要俾錢？**
開工作台、揀行業、讀顏色、睇狀態 —— 全部喺你部機度行，唔使錢，唔使開戶口。
要出真內容嗰陣先要接 AI 服務，嗰陣先算錢。見 `docs/API-MODULES.md`。

**我啲客戶資料會唔會俾人睇到？**
唔會。工作台只喺你部機行（網址係 `127.0.0.1`，即係「呢部機」）。冇上載。

**撳錯咗行業點算？**
返上一步再揀過。未撳最後嗰粒「建立工作台」之前，冇任何嘢寫落硬碟。

**兩個客同名點算？**
工作台會攔住你，唔會靜靜雞把第二個客寫入第一個客個資料夾。改個名再試。

**想先睇下係咩嚟？**
```
python3 -m workbench demo
```
會起五個假客戶，五個唔同行業、四種唔同狀態。睇完刪咗成個 `agency` 資料夾就得。
（每個示範客戶資料夾入面有個 `_DEMO` 檔案，一眼分得出唔係真客。）

**點停？**
返去終端機撳 `Control + C`。

---

## 六、真係卡住

睇下呢個：

```
python3 -m workbench doctor
```

佢專門搵一種情況：**睇落完成，但實際上唔可以出街**。
例如已經排咗程但證據庫係空、有圖但品牌視覺未建立。

冇問題就會話你聽「0 個問題」。
